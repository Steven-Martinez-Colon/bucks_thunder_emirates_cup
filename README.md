# 🏀 Bucks vs Thunder: 2024 Emirates Cup Final Analysis

This project presents a comprehensive shot-by-shot analysis of the December 17, 2024 Emirates Cup Final between the **Milwaukee Bucks** and the **Oklahoma City Thunder**. Using optical tracking data, the analysis explores individual player performance, shot quality, team-level strategy, and defensive impact.

The goal of this report was to generate insights accessible to both analytical and non-analytical stakeholders — blending interactive visualizations with tactical observations to explain how and why the Bucks secured a convincing win.
